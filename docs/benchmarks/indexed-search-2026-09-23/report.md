# 缓存索引后的精确搜索性能

与 [原版基准](../exact-search-2026-09-23/report.md) 使用相同机器、优化级别、合成文本、数量、查询和采样次数。改动基于 `112e15d`，精确源码 SHA-256 保存在结果 JSON。

使用不可变文本快照和后台 actor 索引。索引缓存不区分大小写、规范分解后的 UTF-8 文本，并每 32 个原始字素保存一个位置定位点。先定位候选，再从其所在块的原始边界调用原有搜索函数，保留首个匹配和高亮范围。标题变更产生新的快照版本，删除记录时清理缓存。

快速路径限定为 ASCII 和常用汉字查询；其他查询继续使用原来的匹配器，以保留大小写扩展、部分字素等特殊 Unicode 行为。精确搜索的输入合并等待从 40 ms 调整为 15 ms；正则、模糊和混合模式保留 40 ms。

以下是**索引就绪后的中位数，单位 ms**。后台匹配各测 50 次，搜索任务各测 20 次。搜索任务包含输入等待、后台匹配、结果发布、快捷键和选择更新；不包含输入法或屏幕绘制。

## 验证和复现

- 102 项回归测试通过（排除依赖系统前台应用的旧 `ClipboardTests`）。
- 差分测试比较新旧匹配器的结果、首个匹配范围、中文、重音、Emoji、合字、组合字符、检查点边界，以及随机混合 Unicode 文本。
- 覆盖标题规范等价但编码变化、缓存复用、取消搜索及删除后缓存清理。
- [原始样本及源码哈希](results.json)。[独立工作树测试补丁](benchmark.patch) 可应用到 `112e15d`，含被测生产改动及基准入口。

基准命令与原版一致：使用 `-configuration Debug SWIFT_OPTIMIZATION_LEVEL=-O` 保持测试数据隔离，并仅执行 `MaccyTests/SearchTests/testExactSearchScalingBenchmark`。结果输出 `/tmp/maccy-index-benchmark-results-20260923.json`。
